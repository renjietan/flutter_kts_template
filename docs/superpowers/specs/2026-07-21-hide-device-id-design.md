# 设备卡片隐藏 ID 设计

## 目标

右侧设备列表不再显示设备名称下方的 `dc_*` 设备 ID，并压缩设备卡片高度，减少无效留白。

## 范围

- 从 `DevicePanel.vue` 的设备卡片模板中移除 `row.device.id` 文本节点。
- 设备名称、状态、ESN、当前 IP、进度和错误信息保持不变。
- 将普通设备卡片的最小高度从 `82px` 调整为 `64px`，并移除只服务于 ID 文本的样式。
- 不修改设备对象、`deviceKey`、Vue 列表键、会话状态关联、协议或后端逻辑。

## 测试

- 设备卡片仍显示 MMR200、CCU-Main、CCU-Audio 等设备名称。
- 设备卡片不再渲染任何设备 ID 文本节点。
- 样式回归测试确认设备卡片采用压缩后的 `64px` 最小高度。
- 运行完整前端测试、前端构建、Go 测试及 `go vet`。
